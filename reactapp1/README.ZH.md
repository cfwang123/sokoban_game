# reactapp1 — React 推箱子（教学）

> [English](README.md)


**无需 npm / 无需编译**：浏览器打开即可（CDN React 18 + Babel standalone）。

```bash
cd reactapp1
# 直接双击 index.html，或：
python -m http.server 8765
# 访问 http://localhost:8765/
```

键位：WASD / 方向键，Z 撤销，R 重置。也可点页面按钮。

文件：`js/game-core.js`（纯逻辑）· `js/app.jsx`（组件）· `index.html`。

对照：Vue [`../vueapp1`](../vueapp1) · 原版网页 [`../html_app`](../html_app)
