# vbapp1 — Visual Basic .NET 推箱子（教学）

需要 [.NET SDK](https://dotnet.microsoft.com/)（`dotnet`）。与 `csharpapp1` 同生态的 VB.NET 终端版。

```bash
cd vbapp1
dotnet run
```

键位：WASD 移动，z 撤销，r 重置，q 退出。
