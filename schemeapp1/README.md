# schemeapp1 — Scheme Sokoban (teaching)

> [中文版](README.ZH.md)

R5RS ， [Guile](https://www.gnu.org/software/guile/)、[CHICKEN](https://call-cc.org/) [Gauche](https://practical-scheme.net/gauche/).

## Run

```bash
cd schemeapp1
guile -l game.scm -s main.scm
#
# csi -s main.scm
# gosh -l game.scm main.scm
```

Controls: WASD move, z undo, r reset, q quit.
