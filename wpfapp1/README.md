# wpfapp1 — WPF Sokoban (teaching)

> [中文版](README.ZH.md)

Teaching terminal Sokoban port (`wpfapp1/`).

## Run

```bash
cd wpfapp1
dotnet run
```

Controls: WASD move, z undo, r reset, q quit.
