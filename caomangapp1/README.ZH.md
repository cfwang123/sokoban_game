# caomangapp1 — 草蟒完整推箱子

> [English](README.md)


**草蟒**：中文关键字 Python。本目录**游戏逻辑全部用中文关键字**写在 `.草蟒` 源文件中；`main.py` 仅为关键字翻译运行时（类似编译器前端），**不是**另一套 Python 游戏实现。

```bash
cd caomangapp1
python -X utf8 main.py
python -X utf8 main.py 3
```

| 文件 | 角色 |
|------|------|
| `游戏.草蟒` | 目标语言：核心逻辑 |
| `主程序.草蟒` | 目标语言：12 关主循环 |
| `main.py` | 草蟒运行时（只做关键字翻译 + 执行） |
