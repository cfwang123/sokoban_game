# kotlinapp1 — Kotlin Sokoban (teaching)

> [中文版](README.ZH.md)

Teaching terminal Sokoban port (`kotlinapp1/`).

## Run

```bash
cd kotlinapp1
kotlinc Game.kt Main.kt -include-runtime -d sokoban.jar
java -jar sokoban.jar
```

Controls: WASD move, z undo, r reset, q quit.
