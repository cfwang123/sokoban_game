# tkinterapp1 — Tkinter Sokoban (teaching)

> [中文版](readme.zh.md)

Teaching terminal Sokoban port (`tkinterapp1/`).

## Run

```bash
cd tkinterapp1
python -X utf8 main.py
```

Controls: WASD move, z undo, r reset, q quit.
