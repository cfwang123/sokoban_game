# Changelog

## 1.0.0 — 2026-08-12

- Parenthesis Hell Python 解释器（`ph.py`）：parse / eval / ASCII 编解码
- 对齐 esolangs 与 qpliu 语义：quote / letrec / car / cdr / cons / if / eval
- `hello.ph` 维基 Hello world；`sokoban.ph` 默认 identity（`()`）
- 可玩迷你关卡：`main.py`，棋盘状态为 PH Cons/Nil 树，键位 WASD / z / r / q
- `generate.py`：写入默认 `sokoban.ph`
- `--test`：Hello world、cat、推箱/撤销
