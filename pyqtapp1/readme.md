# pyqtapp1 — PyQt Sokoban (teaching)

> [中文版](readme.zh.md)

Teaching terminal Sokoban port (`pyqtapp1/`).

## Run

```bash
cd pyqtapp1
pip install PyQt5
python -X utf8 main.py
```

Controls: WASD move, z undo, r reset, q quit.
