# pyqtapp1 — PyQt 推箱子（教学）

> [English](readme.md)


教学用 PyQt 桌面版源码，**不强制在本仓库配置 Qt 工具链**。

有 Python 绑定即可运行：

```bash
cd pyqtapp1
pip install PyQt5
python -X utf8 main.py
```

也兼容 PyQt6 / PySide6（自动探测导入）。

键位：WASD / 方向键，Z 撤销，R 重置，Q/Esc 退出。

对照：Tkinter 标准库 [`../tkinterapp1`](../tkinterapp1) · C++ Qt [`../qtapp1`](../qtapp1)
