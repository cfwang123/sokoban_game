# winformsapp1 — WinForms Sokoban (teaching)

> [中文版](README.ZH.md)

Teaching terminal Sokoban port (`winformsapp1/`).

## Run

```bash
cd winformsapp1
dotnet run
```

Controls: WASD move, z undo, r reset, q quit.
