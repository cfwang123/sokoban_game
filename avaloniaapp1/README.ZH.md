# avaloniaapp1 — Avalonia 推箱子（教学）

> [English](readme.md)


跨平台 **Avalonia UI** 教学源码（Windows / Linux / macOS），**不要求在本仓库内编译**。

可选本机运行（.NET SDK + NuGet）：

```bash
cd avaloniaapp1
dotnet run
```

界面用等宽字体字符画展示局面（逻辑与 WinForms/WPF 相同，便于对照）。

键位：WASD / 方向键，Z 撤销，R 重置，Esc/Q 退出。

对照：WPF [`../wpfapp1`](../wpfapp1) · WinForms [`../winformsapp1`](../winformsapp1)
