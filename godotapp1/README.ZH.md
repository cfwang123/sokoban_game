# godotapp1 — Godot 推箱子桌面 demo（教学）

> [English](README.md)


[Godot 4.x](https://godotengine.org/) + GDScript。用编辑器打开本目录即可运行。

## 运行

1. 安装 Godot 4.2+  
2. Project → Import → 选择本目录 `project.godot`  
3. F5 运行  

键位：WASD / 方向键，Z 撤销，R 重置。

## 结构

```
project.godot
main.tscn / main.gd   # 场景与绘制
game.gd               # 状态机
```

对照：`unityapp1/`、`pygameapp1/`。
