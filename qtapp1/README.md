# qtapp1 — Qt Sokoban demo (teaching)

> [中文版](README.ZH.md)

`QWidget` + `QPainter`。 Qt 5.15+ / Qt 6 `qmake` Qt Creator.

## Run

```bash
cd qtapp1
qmake qtapp1.pro
make # nmake / mingw32-make
./sokoban
```

```bat
qmake qtapp1.pro
mingw32-make
sokoban.exe
```

Controls: WASD move, z undo, r reset, q quit.
