# pythonapp1 — Python Sokoban (teaching)

> [中文版](readme.zh.md)

Pure stdlib terminal port: core `game.py` + main loop `main.py`.

```bash
cd pythonapp1
python -X utf8 main.py
```

Controls: WASD move, z undo (through last box push), r reset, q quit.

See also: `pygameapp1/` (Pygame UI, modeled on `html_app`).
